## Front End Basics Using HTML, CSS & jQuery

This section includes foundational concepts and features required for building responsive, interactive front-end applications using HTML5, CSS3, JavaScript, and jQuery.

### Topics Covered

#### jQuery and JavaScript Functions

- **Selectors**
  - Basic, class, ID, attribute, and pseudo selectors
  - Example: `$('#id')`, `$('.class')`, `$('[type="text"]')`

- **Effects**
  - `hide()`, `show()`, `fadeIn()`, `slideDown()`, etc.

- **Traversing**
  - DOM navigation using methods like `parent()`, `children()`, `closest()`, `find()`

- **AJAX**
  - Asynchronous server communication using `$.ajax()`, `$.get()`, `$.post()`

- **Chaining**
  - Apply multiple methods on the same element:  
    `$('#box').fadeIn().css('color', 'red').slideUp();`

- **Events**
  - Event handling with `on()`, `click()`, `submit()`, etc.

- **Data Binding**
  - Dynamically binding data to UI using JavaScript/jQuery

- **Validations**
  - Client-side form validation using RegEx and jQuery

- **Response Management**
  - Handling server responses and updating the DOM accordingly

- **Local Storage**
  - Using `localStorage` and `sessionStorage` for persistent data

---

#### HTML5, CSS3, and JavaScript

- **HTML5**
  - Semantic tags (`<header>`, `<footer>`, `<section>`)
  - Forms, inputs, validations, and media tags

- **CSS3**
  - Box model, Flexbox, Grid, transitions, animations
  - Advanced selectors, pseudo-classes (`:hover`, `:nth-child`), pseudo-elements (`::after`)
  - Shadows, floats, z-index, and specificity

- **Media Queries**
  - Responsive design for multiple screen sizes using `@media`

- **Forms**
  - Validation, input types, form submission handling

- **DOM (Document Object Model)**
  - Manipulation using `document.getElementById`, `querySelector`, etc.

- **JSON Server**
  - Mock backend for simulating API operations in frontend projects
